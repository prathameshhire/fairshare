# Fairshare — Frontend

React + TypeScript + Vite + Tailwind. This is the frontend of the [Fairshare](../README.md) monorepo.

See the [root README](../README.md) for the full project overview, tech stack, and setup instructions.

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
```

The Vite dev server proxies API calls to `VITE_API_URL` (defaults to `http://localhost:3000`). Start the [backend](../server) before logging in.
